# DPGSK membership platform prototype

A clickable prototype, built by BeehiveTech, of the membership and subscription system proposed to the Data Privacy and Governance Society of Kenya (RFP DPGSK/RFP/01/2026).

Open `index.html` in a browser, or deploy the folder as a static site. Choose the Committee (admin) view or the member view and click around. All names, numbers and payments are made-up sample data.
